# TT Robotics Panel — önizleme sürümü

Öğretmen ve yönetici panelinin GitHub Pages'te çalışan önizlemesi: `index.html` tek dosyadır.

- Canlı, paylaşımlı sürüm claude.ai'daki artifact'tır; orada veriler ortak veritabanında tutulur.
- Bu önizlemede veriler yalnızca açan tarayıcının `localStorage` alanında saklanır. Başka bir cihazda açıldığında başlangıç verileri (öğretmen müsaitlik formundan gelen 21 öğretmen, 17 okul, 13 program satırı) görünür.
- Önizleme girişi: yönetici PIN `1234`, tüm öğretmenler için PIN `1234`. Telefon ve mahalle bilgileri bu kopyaya alınmamıştır.
- Sayfa `noindex` işaretlidir; arama motorlarına açık değildir.
